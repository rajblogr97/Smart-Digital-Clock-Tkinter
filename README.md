# Smart-Digital-Clock-Tkinter
Smart Digital Clock is a Python GUI-based application developed using Tkinter and the time module
The application displays the current system time and date in real time, updating automatically every second.

This project includes modern features such as 12/24-hour time format switching, day and full date display, and a dark/light theme toggle, making it more advanced than a basic digital clock.

The project is ideal for beginners to understand event-driven programming, real-time GUI updates, and Tkinter-based interface design.

Key Features

Real-time digital clock with date and day

12-hour / 24-hour format toggle

Dark and light mode support

Automatic update using after() method

Clean and user-friendly GUI

Skills Used

Python programming, Tkinter GUI development, time module usage, event-driven programming, real-time UI updates, GUI styling, and clean code structure.
